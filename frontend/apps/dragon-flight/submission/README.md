# Lucky Flight upload package

Upload `lucky-flight-frontend-2026-10-04.zip` as the current frontend. Despite the filename date, this archive contains the latest build. Its `index.html` belongs at the version root.

Keep the existing math version, or use `dragon-flight-math-2026-09-28.zip` for a new math upload. Encounter presentation maps historical mountain-raptor events to the dragon without changing payouts. The math source files remain in `math/` and replay examples remain in `replay-examples.json`.

Rain and storm use static weather artwork and the original ambience sounds. Eagle, Archaeopteryx, Azure Swift, and woodpecker each have win and loss fight clips, transparent final poses, and the source clips' audio. All audio follows Sound On/Off.

To rebuild the frontend, run `pnpm build` in this app and archive the contents of `build/`. Do not upload source files, original art, tests, or development dependencies. Launch connected play through ACP with the platform-provided session parameters.
